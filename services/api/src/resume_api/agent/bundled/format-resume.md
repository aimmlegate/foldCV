# Format the current resume

Read `references/editorial-rules.md` and check `format_document` in the server
task catalog. This task prepares the current template's formatting while keeping
the exact authored wording, facts, links, assets and bindings.

Read the complete current context, document and working facts through all pages.
Prepare one separate proposal with `format_template` and its complete document
snapshot. Keep formatting separate from rewriting or project actions. Do not
silently apply only one part of a compound request.

The result is a private preview. The model ends its turn while the application
waits for explicit UI Apply. A prepared draft is not a saved document or file.
For supported fragment styling, use the editor's existing formatting controls.

Explicit DOCX or portable-project export uses the checked export action on the
saved current document. It does not export an unapplied proposal. The task does
not provide PDF rendering, legacy archive scripts, shell or filesystem tools.
