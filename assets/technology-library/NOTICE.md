# Technology image library

Every catalog technology has a local image. Devicon logos use the MIT license
(LICENSE); Simple Icons use CC0 (SIMPLE-ICONS-LICENSE). Neutral protocol symbols
use Lucide (LUCIDE-LICENSE). Vendor marks retain their owners' trademarks.
Some standard-library/framework entries use their parent platform's family mark.
Generic protocols use neutral symbols, not invented brand logos. The exact kind,
provider, source URL, revision, original file/hash and PNG hash are in sources.json.
Provider revisions are in upstream.json.

Original assets are retained. PNGs are rendered on a transparent 192 by 192 canvas
with a 12-pixel inset and preserved aspect ratio using resvg-py 0.5.0. Original
brand paths and colors are retained; Simple Icons use their published brand color.
This library is independent of frozen reference-template assets. Import and export
read local files and never send resume data to image providers.
