# ReCV logo concepts

Archived exploration under the former name ReCV. The confirmed product name is
FoldCV. No logo has been selected; these sheets and prompts retain their original
wordmark for reference.

Four visual directions for the ReCV app. Each sheet shows the wordmark, a standalone mark, a rounded app icon, and a smaller mark.

- [01 — Folded R](01-folded-r.png): an R monogram with a document corner.
- [02 — CV ligature](02-cv-ligature.png): a joined C and V.
- [03 — Aligned lines](03-aligned-lines.png): text bars arranged into a compact mark.
- [04 — Return frame](04-return-frame.png): an open frame ending in an arrow.

These PNG sheets are concepts. No direction is selected. A selected mark still needs vector artwork and exports at the actual app icon and favicon sizes.
